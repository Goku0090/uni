ISSUE
─────────────────────────────────────────────────────────────────────────────────
OTP emails are not being delivered to users


ROOT CAUSE
─────────────────────────────────────────────────────────────────────────────────
Email service credentials not configured in .env file
→ System defaults to console backend (prints to console instead of sending)


SOLUTION (5 MINUTES)
─────────────────────────────────────────────────────────────────────────────────

1. GET API KEY
   └─ Go to https://www.brevo.com/
   └─ Sign up (free account)
   └─ Settings → SMTP & API → Copy API Key
   
2. CREATE .env FILE
   └─ Location: e:\login\auth_project\.env
   └─ Content:
      BREVO_API_KEY=YOUR_API_KEY_HERE
      DEFAULT_FROM_EMAIL=noreply@unisync.app
      SECRET_KEY=your-secret-key
      DEBUG=True
      ALLOWED_HOSTS=localhost,127.0.0.1
   
3. RESTART DJANGO
   └─ Kill server (Ctrl+C)
   └─ Run: python manage.py runserver
   └─ Wait for: [SUCCESS] EMAIL BACKEND: Using Brevo...
   
4. TEST
   └─ Run: python quick_email_test.py
   └─ Expected: ✓ SUCCESS: Email send returned 1
   
5. VERIFY
   └─ Open http://localhost:8000/login/
   └─ Login with credentials
   └─ Check email inbox for OTP
   └─ Enter OTP to complete login
