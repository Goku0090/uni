1. PROJECT OVERVIEW
================================================================================

UniSync is a university collaboration platform enabling students to:
✓ Discover and join collaborative projects
✓ Network with peers and find collaborators
✓ Communicate via direct/group messaging
✓ Share skills, interests, and project updates
✓ Manage team members and project tasks
✓ Build portfolio and professional connections

Tech Stack:
  - Backend: Django 4.2.8 + Django REST Framework
  - Database: PostgreSQL (prod) / SQLite (dev)
  - Frontend: HTML templates (Django) + Bootstrap 5 + JavaScript
  - Real-time: Django Channels (WebSockets ready)
  - Email: Brevo/ZeptoMail/Gmail SMTP
  - NLP: NLTK, spaCy, scikit-learn for skill extraction
  - Deployment: Render/Railway ready with Gunicorn

10. KNOWN ISSUES & SOLUTIONS
================================================================================

Email Not Sending:
  → Check BREVO_API_KEY environment variable
  → Verify fallback email configuration
  → Check logs: tail logs/django.log

Profile Photos Not Showing:
  → Ensure MEDIA_URL in settings.py
  → Run: python manage.py collectstatic
  → Check file permissions

Visibility Filter Issues:
  → Verify owner check in ProjectVisibilityFilter
  → Check visibility field in model
  → Public/private logic should be: owner sees all, then visibility

OTP Expires Too Fast:
  → Change timedelta in OTP.generate_otp()
  → Default is 5 minutes
  → Verify is_valid() method implementation
