EMAIL SYSTEM
================================================================================

CONFIGURATION (Priority Order):
  1. Brevo API (BREVO_API_KEY) - Recommended for production
  2. ZeptoMail (ZEPTO_MAIL_API_KEY + TOKEN) - Alternative
  3. Gmail SMTP (EMAIL_HOST_USER + PASSWORD) - Fallback
  4. Console (Development) - Prints to stdout

EMAIL TYPES:
  • Welcome Email (new registration)
  • Welcome Back Email (returning user)
  • Password Reset Email (reset flow)
  • OTP Email (login/registration/reset)

All emails:
  • Plain text + HTML versions
  • Styled with inline CSS
  • Include branding and CTAs
  • Sent via EmailMultiAlternatives

ERROR HANDLING:
  • Failed sends logged and reported to admins
  • Graceful fallback if all backends fail
  • OTP still created even if email fails
