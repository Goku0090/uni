WHAT WAS IMPLEMENTED:
┌─────────────────────────────────────────────────────────────────────────────┐
│                                                                             │
│  Intelligent Project Visibility Filtering                                  │
│  =======================================                                     │
│                                                                             │
│  Projects posted by users are now automatically filtered and only visible  │
│  to other users if they match on:                                          │
│                                                                             │
│  1. ✓ SAME COLLEGE          (+30 points)                                   │
│  2. ✓ SAME TECHNOLOGIES     (+40 points)                                   │
│  3. ✓ SAME INTERESTS        (+30 points)                                   │
│                                                                             │
│  Maximum Score: 100 points                                                 │
│                                                                             │
│  ALWAYS VISIBLE:                                                            │
│  - User's own projects (100% match)                                        │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
