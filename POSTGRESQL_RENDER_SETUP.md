## Deployment Steps

### Step 1: Create Render Account
1. Go to https://render.com
2. Sign up with GitHub/GitLab/Google
3. Create a new "Blueprint" project

### Step 2: Deploy via Blueprint
```bash
# Push render.yaml to your GitHub repo root
git add render.yaml
git commit -m "Add Render deployment configuration"
git push
```

Then:
1. In Render dashboard → Create → Blueprint
2. Select your repository
3. Deploy blueprint (creates web service + PostgreSQL)

### Step 3: Set Environment Variables

In Render Dashboard → Settings → Environment:

```
DATABASE_URL              # Auto-generated by Render
SECRET_KEY                # Generate: python -c "from django.core.management.utils import get_random_secret_key; print(get_random_secret_key())"
DEBUG                     false
ALLOWED_HOSTS             yourdomain.onrender.com
BREVO_API_KEY            [your-brevo-api-key]
DEFAULT_FROM_EMAIL       noreply@unisync.app
GOOGLE_CLIENT_ID         [if using OAuth]
GOOGLE_CLIENT_SECRET     [if using OAuth]
GITHUB_CLIENT_ID         [if using OAuth]
GITHUB_CLIENT_SECRET     [if using OAuth]
```

### Step 4: Run Migrations on Render

After deployment starts:
```bash
# In Render build environment
./build.sh                    # Runs migrations automatically
```

Or manually via Render Shell:
```bash
python manage.py migrate
python manage.py createsuperuser
python manage.py collectstatic --noinput
```

## Local Development with PostgreSQL

### Option 1: Using Docker Compose

Create `docker-compose.yml`:
```yaml
version: '3.8'

services:
  db:
    image: postgres:15
    environment:
      POSTGRES_DB: unisync_db
      POSTGRES_USER: unisync_user
      POSTGRES_PASSWORD: your_secure_password
    ports:
      - "5432:5432"
    volumes:
      - postgres_data:/var/lib/postgresql/data

  web:
    build: .
    command: python manage.py runserver 0.0.0.0:8000
    volumes:
      - .:/app
    ports:
      - "8000:8000"
    environment:
      DATABASE_URL: postgresql://unisync_user:your_secure_password@db:5432/unisync_db
      DEBUG: "True"
      SECRET_KEY: dev-secret-key
    depends_on:
      - db

volumes:
  postgres_data:
```

Run:
```bash
docker-compose up -d
docker-compose exec web python manage.py migrate
```

### Option 2: Local PostgreSQL Installation

**macOS:**
```bash
brew install postgresql@15
brew services start postgresql@15
createdb unisync_db
createuser unisync_user
```

**Windows:**
1. Download PostgreSQL from https://www.postgresql.org/download/windows/
2. Install with pgAdmin
3. Create database and user via pgAdmin

**Linux:**
```bash
sudo apt-get install postgresql postgresql-contrib
sudo -u postgres createdb unisync_db
sudo -u postgres createuser unisync_user
```

## Render-Specific Features

### 1. Automatic DATABASE_URL

Render automatically provides:
```
postgresql://username:password@dpg-xxx.render-instances.com:5432/dbname?sslmode=require
```

Your settings.py automatically parses this with `dj_database_url` (line 107).

### 2. SSL Mode

Render PostgreSQL requires SSL. Your settings handle this:
```python
'OPTIONS': {
    'sslmode': os.getenv('DB_SSLMODE', 'prefer'),
}
```

For Render, set: `DB_SSLMODE=require`

### 3. Connection Pooling

For production, use PgBouncer:
```python
DATABASES = {
    'default': dj_database_url.parse(
        DATABASE_URL,
        conn_max_age=600,  # Connection pooling
        conn_health_checks=True
    )
}
```

## Troubleshooting

### Issue: "psycopg2 not installed"

**Solution:**
```bash
pip install psycopg2-binary
# or
pip install psycopg2
```

Update `requirements.txt`:
```
psycopg2-binary==2.9.9
dj-database-url==2.1.0
```

### Issue: "Database does not exist"

**Solution:**
```bash
# Run migrations
python manage.py migrate

# Create superuser
python manage.py createsuperuser
```

### Issue: "Permission denied for schema public"

**Solution:**
```sql
-- In PostgreSQL psql shell
GRANT ALL PRIVILEGES ON ALL TABLES IN SCHEMA public TO unisync_user;
GRANT ALL PRIVILEGES ON ALL SEQUENCES IN SCHEMA public TO unisync_user;
GRANT ALL PRIVILEGES ON SCHEMA public TO unisync_user;
```

### Issue: "SSL certificate problem" on production

**Solution:** Add to settings.py:
```python
import ssl
ssl._create_default_https_context = ssl._create_unverified_context  # Dev only
```

Better: Update DATABASE_URL to use `sslmode=require`:
```python
if not DATABASE_URL.endswith('?sslmode=require'):
    DATABASE_URL += '?sslmode=require'
```

### Issue: "Connection pool exhausted"

**Solution:** Adjust in settings.py:
```python
DATABASES = {
    'default': dj_database_url.parse(
        DATABASE_URL,
        conn_max_age=300,  # Reduce from 600
        conn_health_checks=True
    )
}
```

## Backup & Recovery

### Automated Backups (Render)

Render automatically backs up PostgreSQL databases:
- Free plan: 7-day retention
- Paid plans: 30+ day retention

Access via: Render Dashboard → Database → Backups

### Manual Backup

```bash
# Create backup
pg_dump -U unisync_user unisync_db > backup.sql

# Restore from backup
psql -U unisync_user unisync_db < backup.sql
```

### Backup on Render

```bash
# Via Render CLI
render backup create --database unisync-postgres

# Download backup
render backup download --database unisync-postgres
```

## Security Best Practices

✓ Use strong `SECRET_KEY` (50+ characters)
✓ Set `DEBUG = False` in production
✓ Use `SECURE_SSL_REDIRECT = True`
✓ Set `SESSION_COOKIE_SECURE = True`
✓ Set `CSRF_COOKIE_SECURE = True`
✓ Keep `ALLOWED_HOSTS` restrictive
✓ Use environment variables for secrets
✓ Enable PostgreSQL password authentication
✓ Restrict database access to app only
✓ Regular backups enabled
