FEATURE REQUEST: UNREAD MESSAGES NOTIFICATION IN NAVBAR
================================================================================

REQUEST:
--------
"When user messages other person, the other user should get its messages 
part in nav bar in the main_home page should indicate on top it"

UNDERSTANDING:
--------------
When User A sends a message to User B:
  → User B's navbar should show notification badge on "Messages" link
  → Badge displays count of unread messages (e.g., "5")
  → Badge disappears when messages are marked as read

CURRENT STATE:
--------------
✅ Message system exists
✅ Read tracking exists (MessageReadStatus model)
✅ Main navbar exists
❌ Notification badge not implemented

PROPOSED SOLUTION:
------------------
1. Add unread message count query to views
2. Pass count to navbar template
3. Display badge with count in Messages link
4. Badge updates when messages are read

IMPLEMENTATION EFFORT:
---------------------
Time: 15-20 minutes
Lines of code: ~30
Database changes: None (0 migrations)
Files to modify: 2 (views.py, main_home.html)
Breaking changes: None
Complexity: Easy

ARCHITECTURE:
--------------
User A sends message
        ↓
Message created in database (receiver=User B)
        ↓
User B visits navbar
        ↓
Query: count unread messages for User B
        ↓
Badge appears on "Messages" link showing count
        ↓
User B clicks Messages
        ↓
Messages marked as read (MessageReadStatus created)
        ↓
Badge disappears on next page load/refresh

DATABASE:
---------
Uses existing models:
  • Message (already has: sender, receiver, created_at)
  • MessageReadStatus (already tracks who read what)

No migrations needed!
No schema changes!
No new tables needed!

CODE CHANGES:
-------------

STEP 1: Add helper function in accounts/views.py
---
def get_unread_message_count(user):
    if not user.is_authenticated:
        return 0
    return Message.objects.filter(receiver=user).exclude(
        read_statuses__user=user
    ).count()
---

STEP 2: Update main_home view in accounts/views.py (line 742)
---
Add to context dictionary:
'unread_message_count': get_unread_message_count(request.user),
---

STEP 3: Update navbar in accounts/templates/main_home.html (line 68-73)
---
Add to Messages link:
<span class="absolute -top-2 -right-2 bg-red-500 text-white text-xs font-bold 
rounded-full w-5 h-5 flex items-center justify-center animate-pulse">
    {{ unread_message_count > 99 ? '99+' : unread_message_count }}
</span>
---
